# RideShareHub – Platform rules (apply to all future screens)

Four separate applications, one shared brand + design system. All UI text in Vietnamese.

| App | Platform | Frame | Navigation |
| --- | --- | --- | --- |
| Passenger | Android/iOS native-style | 390×844 | Bottom tab bar |
| Driver | Android/iOS native-style | 390×844 | Map-first, large controls, pickup/drop-off actions |
| Company | Web | 1440×1024 | Left sidebar + top bar; tables, forms, charts, maps |
| Admin | Web | 1440×1024 | Left sidebar + top bar; approvals, users, monitoring |

Rules: never render mobile apps as responsive desktop sites; never render web dashboards as mobile layouts; no desktop sidebar in mobile apps.
