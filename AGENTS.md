# RideShareHub Agent Guide

## Mandatory Context

Before substantial work, inspect the current repository.

Read the guideline for the current development chapter.

Canonical project artifacts must be used instead of previous chat history.

## Source Precedence

Accepted human decisions
>
Accepted current-stage artifacts
>
Accepted previous-stage artifacts
>
Repository implementation
>
Chat history

## Current Development Stage

- Chapter 1 — Project Brief
- Chapter 2 — Project Context

unless explicitly moved to the corresponding chapter.

## Core Principle

Do not invent product decisions.

Distinguish:

- fact
- decision
- assumption
- open question

## Review Gates

Draft artifacts are not canonical.

Only the human can approve an artifact.
