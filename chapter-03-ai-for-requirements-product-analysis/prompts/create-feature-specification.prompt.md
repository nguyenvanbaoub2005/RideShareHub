# P3.3 — Create Feature Specification

Read `../GUIDELINE.md`, accepted Brief, Context and PRD, plus newer human decisions.

For every capability define actor, preconditions, trigger, success, validation, authorization, failure, recovery, persistence, postconditions and unresolved decisions. Do not choose screens, API, schema or technology.

Save `docs/feature-specification.md` as `Draft — Pending Human Review`. Human approval is required.
