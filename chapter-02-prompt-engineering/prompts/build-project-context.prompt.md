## Goal

Create a reusable project context for RideShareHub.

A fresh AI coding agent should be able to understand
the product without reading previous chat history.

## Context must distinguish

- FACT
- HUMAN DECISION
- ASSUMPTION
- OPEN QUESTION

## Context must define

- product identity
- product boundary
- actors
- domain vocabulary
- core business flow
- invariants
- exclusions
- source precedence
- agent behaviour
